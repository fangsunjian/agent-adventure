# Agent Adventure 重构实施方案 V2

**创建时间**: 2025-01-28
**基于**: Gemini 项目分析 + 用户技术栈要求

## 🎯 实施目标

将 Agent Adventure 从移动端优先的应用重构为现代化的、以桌面端为先的、高性能的全栈应用。

## 📋 分阶段实施计划

### **第一阶段：基础设施升级与环境搭建** (1-2周)

此阶段的目标是引入新的技术栈并搭建好开发环境，为后续的功能迁移做准备。

#### 1.1 样式系统迁移 (Tailwind CSS)

**目标**: 将 Tailwind CSS 从 CDN 引入改为项目构建流程的一部分，以便进行定制和优化。

**步骤**:
1. **安装依赖**:
   ```bash
   npm install -D tailwindcss postcss autoprefixer
   ```

2. **生成配置文件**:
   ```bash
   npx tailwindcss init -p
   ```

3. **配置 tailwind.config.js**:
   ```javascript
   /** @type {import('tailwindcss').Config} */
   export default {
     content: [
       "./index.html",
       "./src/**/*.{js,ts,jsx,tsx}",
     ],
     theme: {
       extend: {},
     },
     plugins: [],
   }
   ```

4. **更新 index.css**:
   ```css
   @tailwind base;
   @tailwind components;
   @tailwind utilities;

   /* 现有自定义样式保留 */
   ```

5. **移除 CDN**: 从 `index.html` 中移除 Tailwind CDN 的 `<script>` 标签

**目标**: 引入专业的状态管理库，解决 Props Drilling 问题。

**步骤**:

   ```bash

   ```

2. **创建 QueryClient**:
   ```typescript

     defaultOptions: {

       },
     },
   })
   ```

3. **创建 Zustand Stores**:
   ```typescript

     activePage: string
     setActivePage: (page: string) => void
   ```

4. **包裹应用**:

#### 2.2 数据获取与变更 (TanStack Query)

**目标**: 将数据获取逻辑迁移到 `useQuery`，变更逻辑迁移到 `useMutation`。

**步骤**:
1. **创建数据服务层**:
   ```typescript
   // src/services/storiesService.ts
   import { supabase } from './supabaseClient'
   import type { Story } from '../types'

   export const storiesService = {
     async fetchStories(userId?: string) {
       const query = supabase.from('stories').select('*')
       if (userId) query.eq('created_by', userId)
       return query
     },

     async saveStory(story: Partial<Story>) {
       return supabase.from('stories').upsert(story)
     },

     async deleteStory(id: string) {
       return supabase.from('stories').delete().eq('id', id)
     }
   }
   ```

2. **创建数据 Hooks**:
   ```typescript
   // src/hooks/useStories.ts
   import { useQuery, useMutation, useQueryClient } from '@tanstack/react-query'
   import { storiesService } from '../services/storiesService'

   export function useStories(userId?: string) {
     return useQuery({
       queryKey: ['stories', userId],
       queryFn: () => storiesService.fetchStories(userId),
     })
   }

   export function useSaveStory() {
     const queryClient = useQueryClient()

     return useMutation({
       mutationFn: storiesService.saveStory,
       onSuccess: () => {
         queryClient.invalidateQueries({ queryKey: ['stories'] })
       },
     })
   }
   ```

3. **重构页面组件**:
   ```typescript
   // 更新 HomePage.tsx
   import { useStories } from '../hooks/useStories'

   export function HomePage() {
     const { data: stories, isLoading, error } = useStories()

     if (isLoading) return <LoadingSpinner />
     if (error) return <ErrorMessage />

     return (
       <div>
         {stories?.map(story => (
           <StoryCard key={story.id} story={story} />
         ))}
       </div>
     )
   }
   ```

#### 2.3 AI 服务重构 (Vercel AI SDK)

**目标**: 使用 Vercel AI SDK 简化与 AI 模型的交互。

**步骤**:
1. **安装依赖**:
   ```bash
   npm install ai
   ```

2. **重构 AI 服务**:
   ```typescript
   // src/services/aiService.ts
   import { generateText, streamText } from 'ai'
   import { google } from '@ai-sdk/google'

   export const aiService = {
     async generateStoryContent(prompt: string, options: any) {
       const { text } = await generateText({
         model: google('gemini-pro'),
         prompt,
         temperature: options.temperature || 0.7,
         maxTokens: options.maxTokens || 1000,
       })
       return text
     },

     streamStoryContent(prompt: string, options: any) {
       return streamText({
         model: google('gemini-pro'),
         prompt,
         temperature: options.temperature || 0.7,
         maxTokens: options.maxTokens || 1000,
       })
     }
   }
   ```

3. **重构游戏页面**:
   ```typescript
   // 更新 GamePage.tsx 使用 useChat
   import { useChat } from 'ai/react'

   export function GamePage() {
     const { messages, input, handleInputChange, handleSubmit } = useChat({
       api: '/api/chat', // 需要创建对应的API端点
     })

     return (
       <div>
         <div className="messages">
           {messages.map(message => (
             <div key={message.id}>{message.content}</div>
           ))}
         </div>
         <form onSubmit={handleSubmit}>
           <input value={input} onChange={handleInputChange} />
         </form>
       </div>
     )
   }
   ```

## 🔄 迁移策略

### 渐进式迁移方针
1. **功能分支开发**: 在 `refactor-v2` 分支进行重构
2. **组件级迁移**: 一次迁移一个组件，确保功能完整
3. **特性开关**: 使用环境变量控制新旧功能切换
4. **并行运行**: 新旧版本可以并行运行和测试

### 风险控制
- **备份策略**: 完整备份当前工作版本
- **回滚计划**: 准备快速回滚到稳定版本的方案
- **测试覆盖**: 核心功能必须有测试覆盖
- **用户反馈**: 分阶段收集用户反馈，及时调整
