# Contributing to Agent Adventure

First off, thank you for considering contributing to Agent Adventure! It's people like you that make Agent Adventure such a great tool.

## How Can I Contribute?

### Reporting Bugs
If you find a bug, please create an issue on GitHub. Please include:
- Your operating system and browser version.
- Steps to reproduce the bug.
- Expected behavior and what actually happened.

### Suggesting Enhancements
If you have an idea for a new feature or an improvement, please open an issue describing your idea and why it would be useful.

### Pull Requests
1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation.
4. Ensure the test suite passes.
5. Make sure your code linting is passing.
6. Issue that pull request!

## Local Development Setup

1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Copy `.env.example` to `.env.local` and add your Supabase credentials.
4. Run `npm run dev` to start the development server.

## Code Style
- We use TypeScript for all new code.
- We use Prettier and ESLint for code formatting and linting.
- Components should be functional components using React Hooks.

## Commit Messages
Please write clear and descriptive commit messages.

Thank you for contributing!
